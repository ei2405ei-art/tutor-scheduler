# Планировщик занятий репетитора

Локальное браузерное PWA-приложение для расписания занятий частного репетитора.
Работает без сервера и без аккаунтов: все данные лежат в `localStorage` браузера.

## Возможности

- Недельный календарь Пн–Вс с итогами недели и остатком предоплаты.
- Ученики: имя, предмет, контакт, ставка, цвет, отключение из расписания.
- Занятия: разовые и серии (один день недели, горизонт 4 недели).
- Перенос занятия: исходное остаётся в своей ячейке недели со статусом «Перенесено».
- Отмена занятия, отметка «Проведено», заметка и домашнее задание.
- Учёт пакетной предоплаты с историей оплат, баланс считается автоматически.
- Мобильный интерфейс от 320 px, работа одной рукой.

## Требования

- Node.js `^22.22.2` или `^24.15.0` (или новее).
- npm.

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # локальная разработка на http://localhost:5173
npm run build      # проверка типов и сборка в dist/
npm run preview    # просмотр собранной версии
npm run lint       # ESLint
npm run typecheck  # TypeScript без emit
npm run test       # Vitest
```

В PowerShell используйте `npm.cmd` вместо `npm`, если выполнение скриптов
заблокировано политикой исполнения.

## Структура

```
src/
  domain/     даты, время, неделя, серии, баланс, команды — без DOM
  storage/    версионированная схема localStorage, валидация и починка
  app/        стор: связывает команды, хранилище и уведомления
  ui/         DOM-примитивы, формы, неделя, ученики, точка монтирования
tests/        юнит-тесты домена, хранилища и приёмочный сценарий
```

Доменная логика не зависит от DOM и может быть проверена отдельно.

## Данные и их сохранение

- Ключ состояния: `tutor-scheduler:state`.
- Резервный слот для исходного JSON: `tutor-scheduler:state:recovery`.
- Схема версионируется в `src/storage/schema.ts`. Повреждённые записи
  отбрасываются из рабочего состояния, а исходный JSON сохраняется целиком
  в резервный слот и не удаляется молча.
- Данные хранятся только в этом браузере. Очистка данных сайта удаляет их,
  синхронизации между устройствами нет.
- Если `localStorage` недоступен, приложение показывает предупреждение и
  не даёт создавать изменения, чтобы введённое не терялось молча.

## Публикация

Сборка публикуется как статические файлы из `dist/`.

```bash
npm run build
```

Для GitHub Pages: workflow `.github/workflows/deploy-pages.yml` собирает
проект и выкладывает `dist/` через Actions. Пути в сборке относительные
(`base: './'`), поэтому приложение работает в любом подкаталоге и не зависит
от имени репозитория — в том числе от кириллического, которое GitHub
публикует в percent-encoded виде. Менять `vite.config.ts` при переименовании
репозитория не нужно.

## Границы MVP

- Напоминания и push-уведомления не входят в MVP.
- Оплата ведётся пакетами занятий, а не почасово; длительность нужна для
  расписания и проверки пересечений.
- ИИ-модуль для домашних заданий выключен по умолчанию и не требует ключа.
